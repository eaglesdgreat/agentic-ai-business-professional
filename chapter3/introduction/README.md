# Introduction to Connecting Your First Data Source

In the last lesson you saw why unified data matters and what a data source inventory captures. Now you put that thinking to work inside the tool. This module is about getting your first real file into Amazon Quick and confirming it landed correctly.

First you'll watch a short demo that audits two source files and uploads one into Amazon Quick. Then you'll do it yourself: document a small set of files in an inventory and upload a transaction dataset into your own workspace.

By the end of this module, you will be able to:

- Audit a raw CSV for its columns, row counts, shared keys, and quality risks before connecting it
- Upload a file and confirm it imports into SPICE
- Read the dataset preview to spot incorrect data types and missing values
