# Getting Started with Amazon Quick

Before you connect data or build a dashboard, it helps to know the lay of the land. Amazon Quick is one platform made of a few connected tools, and each one has a clear job. Knowing what they are and how they fit makes everything that follows easier to place.

This short module orients you to the Amazon Quick ecosystem. You won't build anything yet. You'll come away able to name the main parts you'll use and say what each one is for, so the hands-on lessons feel like steps in a familiar workflow rather than a tour of unfamiliar tools.

Key terms
You don't need to know these yet. These are the terms you will understand by the end of the lesson.

- Amazon Quick
